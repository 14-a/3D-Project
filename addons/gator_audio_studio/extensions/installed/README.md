# Installed GAS Extensions

Each extension lives in its own direct child folder:

`installed/<extension-id>/manifest.json`

GAS 1.0.0 includes two disabled-by-default reference extensions here:

- `com.blackwatergator.gas.example.retro_radio`
- `com.blackwatergator.gas.example.arcade_laser`

Enable them from the GAS **Extensions** panel. Do not place loose extension scripts directly in this folder.
