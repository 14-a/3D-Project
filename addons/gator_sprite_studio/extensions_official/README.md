# Official Gator Sprite Studio Extensions

These extensions are bundled with Gator Sprite Studio, loaded automatically, and exposed as normal sidebar tabs.

- **Gator Ink Lab** (`blackwater.gss.ink_lab`) — outlines, silhouettes, shadows, glow, edge highlights, colour adjustment, pixel cleanup, selections, and extraction into a new layer.
- **Gator Motion Lab** (`blackwater.gss.motion_lab`) — temporary tween previews, Apply/Cancel workflow, reusable tween ranges, linear/arc/wave/shake paths, separate X/Y scaling, easing, and embedded playback.
- **Gator Brush Vault** (`blackwater.gss.brush_vault`) — categorized brush folders, multi-select category reassignment, search, thumbnails, frame/selection capture, transform and random variation, named variation presets, and brush spacing.
- **Aseprite Importer** (`gator_sprite_studio.aseprite_importer`) — imports `.ase` and `.aseprite` files with layers, groups, common blend modes, linked cels, tags, slices, palettes, and frame timing.

Third-party and instructional extensions remain under `extensions_demo/` and are loaded manually.
