Keys

Compiled-in defaults. Rebind in Editor Settings → Shortcuts under poibuilder/*. Viewport keys use physical keycodes, so they survive keyboard layouts.

Godot already binds H (hide node) and [ / ] (animation keys). On first enable the plugin unbinds those three so vertex mode and grid elevation work. Rebind them in Editor Settings if you need them back.
